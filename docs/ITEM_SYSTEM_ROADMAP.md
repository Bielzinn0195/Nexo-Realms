# Sistema de itens — expansão

A primeira versão já possui inventário, equipamento, raridade, ouro, gemas, materiais, upgrade e desmontagem.

A evolução prevista é:

1. Equipamentos por slot
2. Comparação automática
3. Filtros e ordenação
4. Ferreiro
5. Desmontagem
6. Loot por raridade
7. Afixos aleatórios
8. Set bonuses
9. Gemas e encaixes
10. Encantamento
11. Reforja
12. Transmog
13. Itens lendários com efeitos únicos
14. Drops específicos de bosses
15. Baús e recompensas de exploração
16. Inventário persistente no cloud save

O objetivo é entregar uma experiência de action RPG com progressão profunda, sem copiar nomes, arte ou tabelas de outro jogo.
