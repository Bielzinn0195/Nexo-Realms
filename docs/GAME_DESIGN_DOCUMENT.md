# NEXO REALMS — Game Design Document

## Core fantasy
Explore a connected ruined kingdom, master a combat class, discover shortcuts and secrets, complete quests, defeat bosses and build a persistent character.

## Classes
### Cavaleiro
Sword and shield. High defense, reliable close combat, guard/counter mechanics.

### Arqueiro
Fast melee fighter. Mobility, dash chains, critical windows and aggressive combos.

### Mago
Ranged magic specialist. Elemental skills, resource management and lower physical defense.

## World
1. Forest of Beginnings
2. Central City
3. Forgotten Mines
4. Drowned Swamp
5. Ancient Ruins
6. Final Fortress

Areas connect through gates, shortcuts, vertical routes and ability-gated paths. Optional bosses and secrets reward exploration.

## Modes
- Campaign: connected world and narrative progression.
- Arena: online 1v1 PvP, casual/ranked/private rooms.
- Tower: escalating floors with modifiers.
- Boss Rush: standalone bosses and timed runs with leaderboards.

## Combat
Movement, jump, basic attack chains, dodge/dash, class skills, resource management, hit reactions, enemy states, boss phases and arena hazards.

## Progression
Level, attributes, equipment, skills, quests, map discovery, achievements and cosmetic rewards.

## Save
Each account has three independent cloud slots. A slot stores character class, level, inventory, equipment, skills, quests, exploration, bosses, checkpoint and campaign state.

## Input
Automatic device/input detection:
- Touch: virtual joystick + action buttons.
- Keyboard/mouse: keyboard and mouse prompts.
- Controller: gamepad prompts.

The HUD and tutorial change with the detected input mode.
