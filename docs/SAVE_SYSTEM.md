# Save System

Three independent cloud save slots per account.

Each slot contains:
- character
- class
- level
- attributes
- inventory
- equipment
- unlocked skills
- quests
- map discovery
- defeated bosses
- checkpoint
- story state

Autosave triggers:
- entering a new major area
- defeating a boss
- completing a major quest
- acquiring a major ability
- reaching a checkpoint

Manual save is available through Save & Exit.

Cross-platform continuation is a design requirement.
