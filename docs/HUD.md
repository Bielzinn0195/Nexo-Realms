# HUD and Input

## Mobile
Left: virtual joystick.
Right: attack, dash, skills and ultimate.
Top: HP/resource and contextual objective.

## PC
Keyboard/mouse controls with configurable bindings. No virtual joystick.

## Controller
Gamepad prompts replace keyboard prompts.

## Tutorial
NEXO GUIDE teaches controls contextually during the first playable minutes. It explains the detected HUD rather than showing a generic key list.
